# Daily Targets Tracker

A lightweight, mobile-friendly tracker for setting dated targets and seeing daily progress.

## Features

- Organize targets by date and view a weekly progress summary
- Track priorities, status, notes, and optional links
- Export and import JSON backups
- No account or server required

## Privacy

Targets are saved in the browser's local storage on the device where they are entered. They are not synced between users or devices. Anyone using the same browser profile may be able to access its saved targets.

## Run locally

Open `index.html` in a browser.
